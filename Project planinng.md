Project Planning

Project planning defines the activities, workflow, resources, and milestones required to implement the automated standard laptop procurement process. The project is planned around ServiceNow Flow Designer, with the objective of automatically creating and assigning laptop configuration tasks after approval.

1. Project Goal

The main goal is to develop a streamlined workflow for standard laptop requests so that approved requests automatically generate configuration tasks for the Hardware team. This reduces manual intervention and helps minimize user waiting time.

2. Project Activities

The project is divided into the following major activities:

Phase	Activity
Phase 1	Create the Standard Laptop Task flow
Phase 2	Configure the flow assignment to the Standard Laptop service catalog
Phase 3	Configure and test the Standard Laptop Service Catalog
Phase 4	Test approval and automatic Catalog Task creation
Phase 5	Verify task description, status, and Hardware assignment
3. Milestone Planning
Milestone 1 – Flow Creation

Create a Flow Designer flow named “Standard Laptop Task”. Configure the Service Catalog trigger and the Create Catalog Task action. The task should contain the required description, be assigned to the Hardware group, and process approved requests.

Milestone 2 – Flow Assignment

Associate the created flow with the Standard Laptop service catalog item and replace the existing process automation with the new flow.

Milestone 3 – Service Catalog

Use the Service Catalog to access the Standard Laptop item and place an order. The request can then be monitored through its order status and approval details.

4. Testing Plan

The completed workflow should be tested by:

Placing a Standard Laptop request.
Checking the request status.
Opening the request and checking the Approvers section.
Approving the request.
Opening the Requested Item.
Checking the Catalog Tasks section.
Verifying that the configuration task has the correct short description.
Verifying that the task is assigned to the Hardware group.
5. Expected Project Outcome

The planned implementation should provide an automated procurement workflow that reduces manual overhead, improves task allocation, supports timely laptop configuration, and improves the overall efficiency of IT procurement operations.
